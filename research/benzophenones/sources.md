## Notes on confidence assignment

Following the user's tier specification:
- **C1 — Primary** = peer-reviewed primary literature, regulatory documents (FDA orders, SCCS opinions, EU regulations), or official biomonitoring (NHANES) data.
- **C2 — Secondary** = review articles, secondary tabulations, ingredient-database compilations citing primary work.
- **C3 — Inferred** = values not directly measured for the compound but inferred by structural analogy from a closely related compound.
- **C4 — Graph-digitized** = values read off a published spectrum/graph rather than tabulated. (Not used in this set — see C5 list in the cover summary.)
- **C5 — Unknown** = the literature does not contain the specific value at the resolution requested.
